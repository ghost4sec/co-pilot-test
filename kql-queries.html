Sample KQL queries

These queries run in the Log Analytics workspace for project AZURE-1000. They assume the sources on the log sources page are connected. Adjust time ranges to suit.

Failed administrative operations (last 24 hours)

AzureActivity
| where TimeGenerated > ago(24h)
| where CategoryValue == "Administrative"
| where ActivityStatusValue == "Failure"
| summarize Failures = count() by Caller, OperationNameValue
| order by Failures desc

New role assignments

AzureActivity
| where OperationNameValue =~ "Microsoft.Authorization/roleAssignments/write"
| where ActivityStatusValue == "Success"
| project TimeGenerated, Caller, ResourceGroup, _ResourceId
| order by TimeGenerated desc

Resource deletions

AzureActivity
| where OperationNameValue endswith "/delete"
| where ActivityStatusValue == "Success"
| project TimeGenerated, Caller, OperationNameValue, ResourceGroup, _ResourceId

Accounts with many failed sign-ins

SigninLogs
| where TimeGenerated > ago(1h)
| where ResultType != "0"
| summarize FailedSignIns = count() by UserPrincipalName, IPAddress
| where FailedSignIns > 10
| order by FailedSignIns desc

Virtual machines that stopped reporting

Heartbeat
| summarize LastHeartbeat = max(TimeGenerated) by Computer
| where LastHeartbeat < ago(15m)

Average CPU by machine (5-minute bins)

Perf
| where ObjectName == "Processor" and CounterName == "% Processor Time"
| where InstanceName == "_Total"
| summarize AvgCpu = avg(CounterValue) by Computer, bin(TimeGenerated, 5m)
| render timechart

To turn a query into a notification, see alert rules. Reference: Kusto Query Language documentation.
