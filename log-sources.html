Log sources and architecture

Project AZURE-1000 centralises logs in a single Log Analytics workspace. Resources send data through diagnostic settings or the Azure Monitor Agent (AMA). Alert rules query the workspace and trigger an action group that notifies operators.

Design notes

  • Use one workspace per environment so test data stays separate from production.
  • Set retention per table. Keep security-relevant tables longer than performance counters.
  • Apply diagnostic settings with Azure Policy so new resources are covered automatically.
  • Restrict workspace access with Azure RBAC and use table-level access where needed.
