Azure Monitoring Test Lab

This is a public demonstration page about a fictional Azure monitoring project. It contains no real customer data, credentials, or production resources.

Project details

Project ID: AZURE-1000

Environment: Test

Owner: Cloud Security Team

Purpose: Demonstrate centralised Azure logging and monitoring.

Monitoring approach

The design collects Azure activity and diagnostic logs, sends them to a Log Analytics workspace, and uses Azure Monitor alerts to notify operators about important events. Each part is documented on its own page:

  • Log sources and architecture: what is collected, which tables it lands in, and how data flows.
  • Sample KQL queries: queries for failed operations, role assignments, deletions, sign-ins and VM health.
  • Alert rules: example log search, metric and activity log alerts with an action group.
